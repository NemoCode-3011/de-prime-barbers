# De Prime Barbers

A barbershop website concept built to give a grooming business a clear online presence and help visitors explore its services and brand.

## Built with

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- Lucide React and React Icons

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

## Available scripts

```bash
npm run build
npm run lint
npm run preview
```

## Project scope

This repository contains the frontend website. It does not include a separate backend service.
